# Tulas International School - Homepage Redesign

## About the Project

This is a homepage redesign for Tulas International School, Dehradun, created as part of a frontend development assessment.

I wanted to give the homepage a cleaner and more modern look while keeping the important information easy to find. The main focus was on simple navigation, responsive design and adding small animations that make the page feel more interactive.

## Design Approach

I kept the design simple and focused on the information that parents and students would be looking for.

The main colors are deep green, warm beige and muted gold. I used large headings, clean spacing and simple layouts to give the homepage a modern look without making it feel crowded.

The animations are kept subtle so they add some movement without distracting from the content.

## Responsive Design

The website is designed to work on desktop, tablet and mobile screens.

On smaller screens, the navigation changes into a mobile menu, the Hero section changes to a single-column layout, and the other sections adjust their spacing and layout to fit the screen.

## Accessibility

I added basic accessibility improvements such as semantic HTML, descriptive image alt text, accessible labels for icon buttons and aria-expanded for the mobile navigation.

## Theme

The light and dark themes are controlled using React state.

The selected theme is saved in localStorage so that the user's preference stays the same after refreshing the page.

## Project Goal

The goal of this project was to create a professional and easy-to-use school homepage while keeping the code simple, organized and easy to maintain.
